# 🎓 Quick Start Guide - Task Remainder

## 🌟 How to Use Advanced Features

### 🌙 Dark Mode
**Location:** Top-right corner  
**How to use:** Click the moon (🌙) or sun (☀️) icon  
**Effect:** Switches between light and dark themes instantly  
**Persistence:** Your choice is saved automatically

### 📊 Statistics Dashboard
**Location:** Below the header  
**What it shows:**
- Total number of tasks
- Active (incomplete) tasks
- Completed tasks
- High priority tasks requiring attention

**Tip:** Hover over cards for a cool lift effect!

### 🔍 Search Tasks
**Location:** Above the task list  
**How to use:** Type in the search box  
**Searches:** Task names, priority levels, categories  
**Real-time:** Results update as you type  
**Clear:** Delete text to see all tasks again

### 🎯 Filter Tasks
**Buttons:** All | Active | Completed  
**How to use:** Click any filter button  
**All:** Shows every task  
**Active:** Shows only incomplete tasks  
**Completed:** Shows only finished tasks  
**Counts:** Each button shows how many tasks in that category

### 🎨 Priority Color Coding
Tasks automatically show colored left borders:
- **🔴 Red Border** = High Priority (urgent!)
- **🟠 Orange Border** = Medium Priority
- **🟢 Green Border** = Low Priority

### ✅ Managing Tasks

#### Adding a Task:
1. Type task name in the input field
2. Select priority (High/Medium/Low)
3. Select category (General/Work/Personal)
4. Click "ADD TASK"

#### Completing a Task:
- Click the "✓ Complete" button
- Task gets a strikethrough
- Click "↩ Undo" to mark it incomplete again

#### Deleting a Task:
- Click the "🗑 Delete" button
- Task is removed immediately

#### Clearing All Tasks:
- Click "🗑️ Clear All Tasks" button at the bottom
- Confirm in the popup dialog
- All tasks are removed

### 💡 Pro Tips

1. **Quick Search:** Start typing to find tasks instantly
2. **Priority First:** Use filters to focus on active high-priority tasks
3. **Dark Mode:** Switch to dark mode in low-light environments
4. **Stats Check:** Glance at the dashboard to track your progress
5. **Color Scan:** Quickly spot urgent tasks by their red border

### 🔄 Data Persistence
Your data is automatically saved:
- ✅ All tasks
- ✅ Completed status
- ✅ Dark mode preference

Data persists even after:
- Closing the browser
- Refreshing the page
- Turning off your computer

### ❓ Common Questions

**Q: Where is my data stored?**  
A: In your browser's localStorage (stays on your device)

**Q: Can I undo a delete?**  
A: No, but clearing all tasks requires confirmation

**Q: Does search work with filters?**  
A: Yes! Search combines with the active filter

**Q: Can I change priority after creating a task?**  
A: Currently no, you'd need to delete and recreate

**Q: What happens if I have 100+ tasks?**  
A: All features work smoothly, use filters and search!
